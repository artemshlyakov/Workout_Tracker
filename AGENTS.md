## Инварианты
1. Русский mobile-first UX, быстрое логирование веса/повторов/подходов, одна дизайн-система; никакой ложной статистики.
2. **Только бесплатные технологии и тарифы**, никаких платных подключений, секретов, внешних LLM API.
3. **Публичный релиз требует входа**: Supabase Auth (ADR 0007: email+password без подтверждения **только в закрытом личном пилоте**; signup после первого аккаунта выключен; публичный набор пользователей требует нового решения); RLS/grants изолируют A, B и anon. Никакой общедоступной гостевой истории тренировок.
4. В Plan 001 — только демо без сохранения и авторизации, баннер `Демо — данные не сохраняются`; не публиковать как продукт.
5. В Plan 002 — test-only локальный workspace для разработки, без публичного распространения; в настоящем приложении кеш/outbox строго привязан к авторизованному user ID.
6. В постоянной версии запись сначала атомарно фиксируется в IndexedDB (**record + outbox**), затем асинхронно синхронизируется. `Синхронизировано` только после серверного подтверждения.
7. Запрещено смешивать данные разных аккаунтов, даже офлайн; при явном выходе закрывать доступ к локальному кешу и предупреждать о pending-записях. Первый вход всегда онлайн.
8. Компоненты UI не обращаются к Supabase/Dexie напрямую; domain не зависит от React; соблюдай архитектурные порты.
9. UUID сущностей/операций, idempotency, ревизии и tombstones; не обходить RLS и CAS произвольным прямым write API.
10. `service_role`/secret/password/SMTP-credentials нельзя публиковать в `VITE_*`, коде, Pages, логах и коммитах. Auth-секреты пользователя не сохранять самодельным способом.
11. Меняй только файлы в границах активного плана; при изменении контрактов обновляй docs и ADR. Не заявляй о тестах, которые не запускал.
