# Plan 010 — доводка визуального языка

Запрос владельца: сделать обе темы теплее и приятнее, смягчить почти чёрный фон, убрать стерильную белизну, добавить сдержанный декор холста и заменить неочевидный переключатель темы. Экран длинной тренировки остаётся главным рабочим инструментом.

## Границы

- Обновить токены существующей дизайн-системы и их применение на основных экранах: вход, тренировка, история, упражнения, прогресс, профиль, нижние панели.
- Добавить только статичный слабый фоновой акцент вне рабочих карточек. Никаких постоянно движущихся элементов, внешних картинок, новых библиотек или платных сервисов.
- Сделать компактный понятный переключатель солнце/луна и согласованную нижнюю навигацию. Сохранить доступную озвучку, фокус, зоны касания >=44px и `prefers-reduced-motion`.
- Сохранить плотность набора подходов и существующие действия, данные, Auth, Dexie, outbox и Supabase. SQL/RLS/синхронизацию не менять.

## Проверка готовности

1. Обе темы без горизонтальной прокрутки на 360/390px; карточки и границы различимы, подписи и значения графиков читаемы.
2. Смена темы понятна по видимому состоянию, сохраняется после reload; короткая анимация отключается при `prefers-reduced-motion`.
3. Активная вкладка различима без опоры только на цвет; нижняя панель учитывает safe area и не перекрывает ввод.
4. Главная кнопка и заполненные подходы остаются яснее декора. Пустые, ошибочные и ожидающие синхронизации состояния не теряют смысла.
5. `npm run lint`, `npm run typecheck`, `npm test -- --run`, `npm run build`, `git diff --check`; локальный визуальный проход по 360/390px. Физический iPhone и полный облачный браузерный сценарий отдельно отмечать как непроверенные, если они не выполнялись.

Решение по цветам и взаимодействиям: `../design/design-system.md`. Контракты экранов: `../design/screens.md`.
