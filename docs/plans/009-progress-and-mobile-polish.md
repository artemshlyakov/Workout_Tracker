# Plan 009 — график прогресса и мобильная полировка

Запрос владельца: видимый график прогресса, аккуратные миниатюры упражнений без светлых полей, качественный выплывающий список упражнений, отключение масштабирования страницы в PWA. DDX Fitness используется как общий референс для дневника и аналитики; копирование ассетов или интерфейса не требуется.

- Показывать график на основании только завершённых записей: общий дневной объём и лучший рабочий вес выбранного упражнения. Одна запись даёт точку, ноль записей — честное пустое состояние. Даты и числа в подписях, без вымышленных значений.
- Выбор упражнения оформить адаптивной панелью с поиском, крупными зонами касания, фокусом и закрытием по Escape/кнопке. Существующие фильтры библиотеки и карточки сохранить функциональными.
- Миниатюры заполнить кадром без цветового смешивания и светлого фона. Полные иллюстрации в описании остаются доступны.
- Для установленной PWA и страницы ограничить pinch zoom через viewport/touch-action и браузерные iOS gesture events по решению владельца; системный Accessibility Zoom не блокировать, размер полей ввода >=16 px сохранить.
- Проверить lint/typecheck/tests/build и Chromium 360/390 px на данных с одной и несколькими завершёнными тренировками, темы, список и изображения. Обновить design/product/operations/progress. SQL/Auth/sync не менять.
