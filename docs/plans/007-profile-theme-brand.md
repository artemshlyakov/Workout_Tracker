# Plan 007 — профиль, темы и домашняя иконка

Основание: запрос владельца после публикации PR #9 (начато 2026-10-23, проверка 2026-10-24). Работа от `main` без изменений Auth и облачной схемы.

1. Обновить минималистичную иконку iPhone/PWA, проявить её в интерфейсе и проверить манифест.
2. Дать тёмную и светлую темы с явным переключателем, запоминанием на устройстве и сдержанными анимациями, учитывающими reduced motion.
3. Добавить понятный профиль с email, состоянием синхронизации и выходом. Управление резервной копией убрать с первого экрана в отдельный раскрываемый раздел: сохранность данных и ручное восстановление остаются доступны.
4. Разрешить убрать личное упражнение из списка без потери исторических тренировок. Tombstone через существующий outbox/RPC; действующую тренировку защитить от удаления используемого упражнения. История и личный экспорт должны хранить названия архивных упражнений.
5. Проверить 360/390 px, светлую/тёмную тему, установочный значок, релевантные тесты и CI; один PR и публикация Pages.

Масштабирование всей страницы остаётся для доступности. Поля ввода >=16 px предотвращают автоматическое приближение iOS при фокусе. Дополнительные CA, смена регистрации или новые облачные таблицы не требуются.

Результат: реализовано, локальные проверки и точные ограничения записаны в `docs/PROGRESS.md` и ADR 0009. Физический iPhone/Safari и полный Auth/offline/online сценарий остаются отдельной проверкой владельца; HTML viewport разрешает pinch zoom по доступности.
