# Личный тренировочный дневник — завершённый продуктовый этап

Основание: актуальный main `cc06cfa` после PR #7 и #8. Владелец 23 октября 2026 поручил исследовать аналоги, довести приложение и публиковать проверенные изменения на Pages. Целевое устройство — iPhone, личный вход уже работает.

1. Безопасное получение обновлений облака с пагинацией и защитой pending-записей; повторные попытки, явные конфликты и экспорт.
2. Каталог упражнений, поиск/фильтры, изображения и описание, личные упражнения.
3. Сценарий тренировки: шаблоны/повтор, предыдущие значения, добавление/удаление/порядок, черновики, отдых, завершение и исправление.
4. Календарь, история, результаты по упражнениям, резервные данные.
5. PWA для iPhone, обновление только по действию пользователя, мобильные проверки и CI; публикация main.

Сохраняются React/TypeScript, Dexie, Supabase и существующий RPC. Смена стека не решает текущих продуктовых проблем. Любые неизвестные результаты реального браузерного Auth/offline/online теста фиксируются отдельно и не выдаются за успешные. Тестовые A/B, настройка signup и сертификаты не изменяются.

Реализация и локальные проверки завершены; точные результаты, известные ограничения и остаточный браузерный gate — в актуальном `docs/PROGRESS.md`. Публикация идёт через единственный PR этой ветки и CI, затем workflow main; физический Safari не объявляется проверенным.
