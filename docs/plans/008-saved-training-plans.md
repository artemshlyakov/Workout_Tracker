# Plan 008 — сохранённые программы и запуск тренировки

Запрос владельца: заранее собрать собственную тренировку с упражнениями, запускать состав повторно, записывать подходы лишь во время тренировки; редактировать/удалять сохранённую тренировку, видеть название проведённой тренировки по дате; указать рост и вес в профиле. «Грудь и бицепс» было только примером, автоматически такой шаблон не создаётся.

- Программа — отдельная owner-scoped запись (UUID, title, упорядоченные названия упражнений, revision, tombstone), без подходов и календарной даты. Запуск атомарно создаёт обычную тренировку через существующий repository/outbox; прошлые записи не меняются при редактировании программы.
- Создание/редактирование/удаление программы: Dexie+outbox и Supabase RPC с RLS/CAS/idempotency. Миграция только добавочная, до публикации проверяется на реальном проекте.
- Календарь показывает названия записей выбранного дня; шаблоны не считаются проведёнными тренировками.
- Рост/вес — личные параметры, не смешиваются с рабочим весом подходов и статистикой. Их сохранение и область действия указываются в интерфейсе.
- Проверки: существующая история/outbox без потери, перезапуск, шаблон с несколькими упражнениями, редактирование, удаление, облачный round-trip, мобильные 360/390, CI/Pages.
