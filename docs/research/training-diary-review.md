# Обзор дневников тренировок — 23 октября 2026

Изучены официальные описания Strong, Hevy и FitNotes. Это сравнение полезных сценариев, а не рейтинг по рекламным заявлениям.

| Источник | Полезный сценарий | Решение для Workout Tracker |
| --- | --- | --- |
| [Strong: первая тренировка](https://help.strongapp.io/article/229-my-first-workout) | Добавление упражнений, отметка выполненного подхода, повтор тренировки | Явная фиксация подхода, предыдущие значения, повтор состава без фиктивных результатов |
| [Strong: таймер](https://help.strongapp.io/article/231-rest-timer) | Отдых между подходами | Отсчёт по абсолютному времени; корректное восстановление после сворачивания |
| [Hevy: функции](https://www.hevyapp.com/features/) | Каталог, история, результаты, шаблоны | Поиск по мышцам/оборудованию, изображения, программы-стартеры и повтор истории |
| [Hevy: календарь](https://help.hevyapp.com/hc/en-us/articles/35380117933207-Track-Your-Workout-Consistency-with-the-Calendar-and-Streak-Features) | Дни тренировок и переход к записи | Месячный календарь и фильтр истории по дате |
| [FitNotes: настройки](https://www.fitnotesapp.com/settings/) | Экспорт и восстановление данных | Явное резервное копирование, проверка владельца и защита локальных изменений |
| [DDX Fitness: App Store](https://apps.apple.com/ru/app/ddx-fitness/id1631792129) | Дневник, календарь и раздел аналитики в актуальных версиях | Ориентир на видимый прогресс и аккуратный мобильный выбор упражнений; графики строятся только по нашим собственным завершённым записям |

Приоритет: запись → сохранность → быстрый повтор → история и прогресс. Социальная лента, медицинские рекомендации и платные интеграции не нужны для личного дневника.

Каталог: [free-exercise-db](https://github.com/yuhonas/free-exercise-db), snapshot `f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5`, 876 записей. Исходник распространяется под Unlicense; лицензия включена в `public/licenses/free-exercise-db.txt`. Русские названия добавлены для распространённых силовых движений; остальные названия и исходные инструкции остаются на английском. 272 изображения для 136 локализованных упражнений поставляются на Pages из закреплённого источника; остальные загружаются с pinned GitHub URL. Все картинки кешируются PWA по мере просмотра, без скачивания всего набора при установке. Это справочник, а не утверждение о наличии всех существующих вариантов упражнений. Ввод журнала рассчитан на силовые подходы с весом и повторениями.
