# ADR 0004 — Локальная база до облачной интеграции (пересмотр)

**Status: SUPERSEDED by ADR 0006 (2026-10-20).** Старое решение о публичном гостевом workspace **не действует**.

## Старый подход
Ранее предполагалось разрешить анонимные локальные тренировки и затем привязывать их к аккаунту.

## Актуальный подход
- Plan 002 допускает локальный тестовый профиль **только для разработки** IndexedDB и PWA.
- Пользовательский релиз **требует авторизацию**; новые производственные локальные пространства создаются только в контексте ранее аутентифицированного `user_id`.
- Никакого автоматического переноса тестовых/гостевых тренировок в новую учётную запись.
- Локальный outbox при смене пользователя всегда изолирован от другого аккаунта.

См. `0006-required-auth-private-accounts.md` и `docs/architecture/auth.md`.
