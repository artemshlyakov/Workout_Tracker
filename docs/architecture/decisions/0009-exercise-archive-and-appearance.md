# ADR 0009 — личный каталог и внешний вид PWA

Принято по запросу владельца после выпуска PR #9.

1. Удаление упражнения из «Моих» выполняется как существующий RPC tombstone `exercise.delete` через атомарную Dexie-транзакцию с outbox. Редактируемое сейчас упражнение удалить нельзя. Упражнение из завершённой тренировки исчезает из личного каталога, но запись упражнения, его название и подходы остаются в истории. Архивное упражнение нельзя повторно выбрать из личного списка; его можно создать/выбрать заново под новым UUID. Pull сохраняет tombstone. Экспорт и импорт личной копии восстанавливают прошлую тренировку с его названием. Серверный RPC запрещает новые подходы к архивному упражнению, поэтому прежняя запись доступна для просмотра и повтора состава, но её исправление блокируется после архивирования. SQL, RLS и Dexie version не меняются.
2. Профиль показывает email, дату аккаунта при наличии, количество завершённых тренировок и подходов из текущего журнала, текущий статус облака и выход. Резервное копирование доступно в раскрываемом разделе профиля и в сценарии конфликта. Его удаление на уровне данных опасно: IndexedDB может очиститься, cloud может быть недоступен, а импорт служит для восстановления. Основной экран освобождён от JSON-кнопок.
3. Выбор светлой/тёмной темы хранится только в localStorage браузера. Данные тренировок и Auth изолируются прежним образом. Тема не требует изменений Supabase. CSS сохраняет контраст и учитывает reduced motion. iPhone icon 180 px, manifest 192/512 px и favicon сделаны из одного знака с безопасной зоной для маски.
4. Масштабирование всей страницы сохраняется по доступности. Поля ввода имеют 16px, что устраняет автоматическое приближение Safari при вводе. Полный браузерный Auth/offline/online gate остаётся открытым и не объявляется проверенным этим этапом.
