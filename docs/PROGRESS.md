# Прогресс Workout Tracker

## Текущий этап

Plan 002 — локальное хранение и PWA в тестовой области разработки. Ветка `feat/plan-002-offline-persistence`.

## Выполнено

- Plan 001 объединён в `main` через PR #1.
- Добавлены Dexie-таблицы workspace, workout, exercise, workoutExercise, exerciseSet, outbox и syncState.
- Изменения записи и outbox фиксируются в одной IndexedDB-транзакции; у сущностей и операций стабильные UUID, локальные ревизии и tombstones.
- Экран загружает данные через порт хранилища, показывает статус после commit и ошибку при сбое.
- Реализованы версионированные JSON экспорт и атомарный импорт тестовой области.
- Добавлена PWA-оболочка с кешем статических файлов без runtime-кеша API.

## Проверки

- `npm run lint` — успешно.
- `npm run typecheck` — успешно.
- `npm test -- --run` — 15 тестов успешно (7 расчётов + 8 тестов хранилища).

- Chromium/Playwright: 360×800 и 390×844 без горизонтального переполнения; изменённый вес сохранился после перезагрузки и офлайн-перезагрузки, а также проверены добавление, удаление, отмена, экспорт/импорт. Все видимые поля и кнопки ≥44×44 px.

## Известные ограничения

- Локальная область предназначена только для разработки. Нет авторизации, Supabase и синхронизации между устройствами.
- Ввод с ошибкой остаётся черновиком и не переживает перезагрузку, пока не будет исправлен.
- IndexedDB может быть очищена браузером или пользователем; JSON-копия нужна для резервирования.
- Service Worker обслуживает только статическую оболочку; хранение тренировок обеспечивает IndexedDB.
