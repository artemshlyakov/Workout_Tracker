# Прогресс Workout Tracker

## Текущий этап

Plan 001 — демонстрационный экран активной тренировки. Ветка `feat/plan-001-workout-ui`.

## Выполнено

- Создан минимальный проект React, TypeScript и Vite.
- Добавлены локальное состояние, редактирование названия, веса и повторов, добавление и удаление с отменой последнего удаления.
- Расчёт объёма и проверка чисел вынесены в `src/domain`.
- Добавлены CSS-токены и мобильные компоненты в стиле Performance Dark × Athletic Pro.
- Добавлены модульные тесты и настройки ESLint, TypeScript и Vitest.

## Проверки

- `npm run lint` — успешно.
- `npm run typecheck` — успешно.
- `npm test -- --run` — 7 тестов успешно.
- `npm run build` — успешно.
- Визуальная проверка 360×800 и 390×844 не завершена: доступный Chromium не создал скриншот в этой среде. Требуется ручная проверка в браузере на телефоне или через DevTools.

## Известные ограничения

- Данные сбрасываются при перезагрузке: сохранение ещё не реализовано.
- Нет входа, Supabase, IndexedDB, Service Worker, истории и синхронизации.
- Этот этап предназначен только для проверки интерфейса, не для реальных записей.
